# IO Project Assistant

Claude Code plugin that builds the daily I&O project status report from Teams, Jira, Confluence and SharePoint.

Install:

```
/plugin install ioproject-assistant --marketplace ig-kul-sec/ioproject-assistant
```

Then type `/ioproject-assistant:setup` once, and `/ioproject-assistant:run-report` whenever you need a report.
